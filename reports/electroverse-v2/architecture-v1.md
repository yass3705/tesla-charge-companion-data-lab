# Electroverse V1 — architecture observée (15 octobre 2026)

Référence de code : Data Lab `origin/main` `2d4a0ebeb746bfad79a507afa333378d2790307c`. Cette étude lit les processus existants ; elle ne les exécute ni ne les modifie. La PR #219 (filtre de connecteurs) et la PR #330 (idée exploratoire) sont séparées de cette branche.

## Chaîne effective France

1. `electroverse-france-daily-delta.yml` démarre à 22:47 UTC (ou manuellement/trigger), utilise `ELECTROVERSE_API_KEY`, Node 22, zoom 9, 8 travailleurs de tuiles. `electroverse_daily_delta_selector.mjs` parcourt 8 régions France et outre-mer via les tuiles PBF `rest/locations/tiles/elastic`. Il extrait les `_id` de la couche `hits`, déduplique, puis conserve par tuile les anciens IDs si une requête échoue. Les nouveaux IDs sans mapping IRVE sont seulement rapportés ; une disparition n'efface pas le cache.
2. Le sélecteur lit le mapping `irve_location_mapping.json`, les 128 shards et les échecs précédents. Il sélectionne nouveaux IDs **déjà mappés**, mappings sans cache et échecs à reprendre. La sélection est écrite dans `reports/electroverse/incremental-selection.json`.
3. `electroverse_hybrid_refresh.mjs` interroge GraphQL par alias de 5 emplacements, à concurrence 2 et pause de vague de 750 ms. Un alias absent est retenté individuellement, puis par pagination EVSE `first:5` avec curseur (jusqu'à 500 pages, 3 tentatives/page). Les stations connues comme paginées sont interrogées directement en mode paginé. Le client possède timeout 45 s, codes 429/5xx avec `Retry-After` exposé, et retries configurables ; le refresh limite lui-même les tentatives et cadence les fallbacks.
4. La projection tarifaire conserve pour chaque connecteur PK, kW, speed, `isChargingFree`, standard, `priceComponents` et `complexPricingDetail` (restrictions de date, semaine, heure, durée, devise). Le SHA-256 de la projection stable sert à éviter la réécriture des stations inchangées. Les stations modifiées sont réparties sur 128 shards par premier octet SHA-1 du PK modulo 128 ; `checked-at.json` garde les contrôles sans changement de tarif. Le manifeste et le rapport d'échecs sont réécrits en fin de run.
5. Le full hebdomadaire démarre dimanche 00:17 UTC, en 4 jobs séquentiels de 6 000 mappings maximum. Il utilise la même collecte hybride et pousse les shards/checkpoints sur `main`. Les jobs continuent après des échecs isolés, enregistrés dans le rapport.
6. Le constructeur d'overlay EVSE France et Production consomment ensuite des données Data Lab épinglées. Le mapping exact, les règles de statut, le filtre EF/Type 2/CCS et les gardes de prix sont distincts de ce collecteur ; le prototype V2 ne les modifie pas. L'overlay exige des preuves de statut complètes et fraîches avant publication, selon `docs/electroverse-status-incremental-repair-2026-10-10.md` et la PR #219.

## État observé

- Manifeste tarifaire du 11/10 : **22 818 stations**, 128 shards, **346 210 374 octets** déclarés par leurs métadonnées ; plus gros shard 3 732 790 octets. Dernier bloc hebdomadaire : 4 818 sélectionnées, 490 changées, 4 328 inchangées, 0 échec, 963 requêtes batch et 1 185 fallbacks, soit 2 148 requêtes et 6 232,79 s. Le run complet [38116023164](https://github.com/yass3705/tesla-charge-companion-data-lab/actions/runs/38116023164) a duré de 05:49 à 14:39 UTC (~8 h 50, 4 jobs successifs). Ce temps est celui du run, pas une mesure de facturation Actions.
- Delta du 15/10 : [38662583553](https://github.com/yass3705/tesla-charge-companion-data-lab/actions/runs/38662583553), 568 tuiles, zéro tuile échouée, 167 381 IDs, 3 057 nouveaux, 3 587 disparus, **0 nouveau ID mappé et 0 station sélectionnée** ; durée du run ~66 s. Un run réussi ne prouve donc pas une actualisation des tarifs.
- Benchmarks archivés du 28/09 : lot 6–9 → HTTP 400 ; lot 5/concurrence 2 → 150/150 rendues dans l'échantillon ; concurrence 3 → 75/150 rendues avec réponses partielles. Le benchmark hybride 1 000 stations a validé 1 000/1 000 après 112 fallbacks, 312 requêtes et 1 188,62 s. Ces essais historiques ne garantissent pas la même capacité API aujourd'hui.
- Le dernier rapport de statut consulté (partition 5, 15/10) ne vérifie que 348/1 426 lieux avant 48 erreurs persistantes. Ce recensement est distinct du cache tarifaire et ne valide aucun overlay national incomplet.
