# Hauts-de-France coverage

All five departments are accounted for at public-network research level. Aisne uses USEDA DIRVE 02, Somme uses TE80/Freshmile, and current first-party local evidence confirms Pass Pass footprints in Nord, Oise and Pas-de-Calais. Pass Pass pricing is classable only after preserving each station category and the tariff displayed on the station; no universal regional tariff is invented.
